# 组件 API

组件页同时提供最小用法、交互示例和自动生成的 Props、Events、Slots 表格。

## 基础组件

- [Button 按钮](/components/button)：语义类型、尺寸、加载与禁用状态。
- [Icon 图标](/components/icon)：内置图标渲染。
- [Avatar 头像](/components/avatar)：用户头像、徽标与形状。
- [Badge 徽标](/components/badge)：数字与红点标记。
- [Cell 单元格](/components/cell)：列表、导航与操作行。
- [Checkbox 多选指示](/components/checkbox)：选择状态展示。
- [CopyableText 可复制文本](/components/copyable-text)：文本展示与复制。
- [Empty 空状态](/components/empty)：空内容反馈。
- [Input 输入框](/components/input)：文本输入与状态。
- [IconButton 图标按钮](/components/icon-button)：图标操作按钮。
- [ScrollToTop 回到顶部](/components/scroll-to-top)：长列表快速返回顶部。
- [Skeleton 骨架屏](/components/skeleton)：加载占位。
- [Switch 开关](/components/switch)：布尔状态切换。
- [Resizable 拖拽尺寸](/components/resizable)：拖拽调整区域尺寸。
- [Text 排版文本](/components/text)：语义化文本排版。

## 反馈组件

- [ActionSheet 操作菜单](/components/action-sheet)：底部操作菜单。
- [Modal 弹窗](/components/modal)：模态内容与操作。
- [Popup 弹出层](/components/popup)：非模态浮层。
- [Toast 轻提示](/components/toast)：短时状态反馈。
- [StatusBanner 状态横幅](/components/status-banner)：连接与业务状态提示。
- [Notification 消息通知](/components/notification)：通知展示与管理。
- [EmojiPicker 表情选择](/components/emoji-picker)：表情浏览与选择。
- [ImageViewer 图片预览](/components/image-viewer)：图片查看与缩放。

## 数据展示

- [PresenceAvatar 在线头像](/components/presence-avatar)：带头像的在线状态展示。
- [PresenceSelector 状态选择](/components/presence-selector)：在线状态选择。
- [UserCard 用户卡片](/components/user-card)：用户资料展示。
- [GroupCard 群组卡片](/components/group-card)：群组资料展示。
