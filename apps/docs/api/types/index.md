# 类型与常量

使用 `import type` 导入纯类型，使用常量避免硬编码 SDK 字符串。

- [消息类型](/api/types/messages)：`UiMessage`、消息体、发送状态和结构型守卫。
- [会话类型](/api/types/conversations)：`UiConversation` 字段与草稿、提醒和置顶信息。
- [联系人与群组类型](/api/types/contacts-groups)：`UiContact`、`UiContactInvite`、`UiGroup` 和 `CreateGroupParams`。
- [在线状态与主题类型](/api/types/presence-theme)：在线状态、主题模式、密度和动画配置。
- [SDK 中立契约](/api/types/sdk-contract)：UIKit 上下文、通知、日志和消息转换。
- [常量](/api/types/constants)：会话、消息、群角色、在线状态和流式消息常量。

数据概念与默认展示规则见[术语与数据模型](/guide/data-model)。
