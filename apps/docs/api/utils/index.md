# Utils

工具函数均从 `@easemob-community/uikit-im` 主入口导入。

- [消息格式化](/api/utils/format-message)：`createMessageFormatter`、`isValidMessageType`。
- [会话摘要与显示名](/api/utils/resolve-last-message-text)：摘要标签、最后消息解析和展示名回退。
- [Mention 工具](/api/utils/mention)：发送前过滤仍有效的 @ 提及。
- [Core 工具](/api/utils/core)：时间、链接、SDK 错误、下载和浮层层级。
- [通用工具](/api/utils/general)：`isEmpty`、`debounce`、`throttle`。
