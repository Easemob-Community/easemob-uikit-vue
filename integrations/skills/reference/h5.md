# H5 适配（安全区 / 键盘 / 下拉刷新 / 长按 / 页面栈）

移动端 H5 场景只需在 `<EmUIKitProvider>` 上配置 `h5` 属性，组件自动处理安全区、软键盘、下拉刷新、长按交互。

## 开启适配

```vue
<EmUIKitProvider
  app-key="your-app-key"
  :h5="{
    safeArea: true,
    keyboardAdapt: true,
    pullRefresh: 'auto',
  }"
>
  <EmChatContainer />
</EmUIKitProvider>
```

## 配置项

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `safeArea` | `boolean` | `false` | 刘海屏/灵动岛安全区内边距；顶部 header、底部 footer、popup 自动避让 |
| `keyboardAdapt` | `boolean` | `false` | 软键盘弹起时把键盘高度同步给输入组件，消息列表自动滚到底部 |
| `pullRefresh` | `boolean \| 'auto'` | `false` | 列表下拉刷新；`'auto'` 触屏设备自动开启 |
| `fontScale` | `number` | `1` | 字号缩放（建议用 `theme.fontSize` / `setFontSize` 替代） |

## 安全区

安全区通过 CSS 变量 `--uikit-safe-*` 透传，开启后 `chat-container`、`chat` header、`address-book-container`、
`popup`、`scroll-to-top`、`message-input`、`conversation-list` 等自动加内边距。纯 PC 网页保持 `safeArea: false`。

## 键盘适配

开启后 UIKit 监听 `window.visualViewport` 变化得到键盘高度，输入框随键盘上移，焦点时消息列表滚到底部。
**不需要在业务代码里手动监听 `resize` / `visualViewport`**。

## 长按交互

H5 长按菜单统一封装在 `useLongPress` 中（touchmove 阈值、长按时临时禁止 body 滚动），业务层无需处理。

## 页面栈导航

移动端单栏布局下，会话列表点击后跳转聊天页，用 `conversation-click` 事件：

```vue
<EmConversationContainer
  @conversation-click="(cvs) => router.push(`/chat/${cvs.id}`)"
/>
```

## 读取 H5 状态

```ts
import { useUIKit } from '@easemob/uikit'

const { h5 } = useUIKit()
h5.isMobile.value        // 是否移动端（width < 768）
h5.keyboardHeight.value  // 当前键盘高度
h5.safeAreaInsets.value  // { top, right, bottom, left }
```

## 注意事项

- H5 状态统一来自 `useUIKit().h5`，**不要**在业务组件里自己监听 `resize` / `visualViewport` / `keyboard`。
- 安全区只通过 `--uikit-safe-*` 传递，组件样式里不直接写 `env(safe-area-inset-*)`。
